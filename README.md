# Fluxy

An interactive bot for the Discord platform.

## Version

**v1.7**

> [!IMPORTANT]
> This is the only open-source release of Fluxy's source code.

## Technologies

- [Discord.js](https://discord.js.org/) — A library for interacting with the Discord API.
- [Disfox](https://disfox.js.org/) — The framework used to develop the bot (**v0.0.8**).
